# Sources and data notes

1. NIKE, Inc. FY2026 Form 10-K (official investor relations filing, filed July 15, 2026):
   https://investors.nike.com/sec-filings/all-sec-filings/content/0000320187-26-000088/nke-20260531.htm
   Used for reported company-level revenue, Nike Brand footwear/apparel/equipment, Nike Direct and wholesale figures. Values are in USD millions and are rounded/transcribed from the filing's tables.

2. VISUELLE fashion product forecasting research:
   https://arxiv.org/abs/2109.09824
   Research describes product-level fashion sales forecasting using data from Nuna Lie, a separate Italian fashion retailer. It is not Nike data and is not bundled with this project.

3. VISUELLE2.0 project code / dataset information:
   https://github.com/HumaticsLAB/visuelle2.0-code
   Dataset access and setup details are provided by the research project. This is an advanced optional extension, not required to run the included dashboard.

## Data limitations
Nike public financial reporting provides aggregated company, product-line, geography, and channel results, not complete model-by-model annual sales. The included product-level demo file is synthetic and explicitly labelled as such. It demonstrates application functionality only.
